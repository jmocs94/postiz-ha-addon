# Postiz Temporal

Temporal workflow server that runs Postiz's scheduled posts and background jobs. Uses PostgreSQL for persistence and visibility (no Elasticsearch). Not exposed to your LAN.

Part of the **Postiz for Home Assistant** app suite. See the repository
[README](../README.md) for the full installation guide and the **Documentation**
tab of this app for its options.

Upstream: temporalio/auto-setup:1.28.4 · Architecture: amd64
