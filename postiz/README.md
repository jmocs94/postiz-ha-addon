# Postiz

Self-hosted Postiz social media scheduler, served on port 4007. Requires the Postiz PostgreSQL, Postiz Redis and Postiz Temporal apps from this repository.

Part of the **Postiz for Home Assistant** app suite. See the repository
[README](../README.md) for the full installation guide and the **Documentation**
tab of this app for its options.

Upstream: ghcr.io/gitroomhq/postiz-app:v2.25.0 · Architecture: amd64
