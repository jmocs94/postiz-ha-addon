# Postiz PostgreSQL

PostgreSQL 16 server that holds the Postiz database and Temporal's two databases (`temporal`, `temporal_visibility`), each with its own user. Not exposed to your LAN.

Part of the **Postiz for Home Assistant** app suite. See the repository
[README](../README.md) for the full installation guide and the **Documentation**
tab of this app for its options.

Upstream: postgres:16.15-trixie · Architecture: amd64
